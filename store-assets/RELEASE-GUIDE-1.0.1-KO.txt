【4】 나머지 확인
----------------------------------------
- 스크린샷/설명: 그대로 (변경 불필요)
- App Review Information → Notes: 기존 GUEST ACCESS 내용 유지 + 맨 위에 한 줄 추가:
  "1.0.1 is a visual/interaction update (sheets, haptics, avatar crop, country picker); no new data collection."
- 암호화 질문: 안 뜸 (플래그 내장)
- Version Release: "Manually release this version" 선택 (승인 후 직접 게시)

【5】 제출
----------------------------------------
우상단 "Add for Review" → "Submit to App Review"
→ 심사 보통 24시간 내 → 승인 메일 오면 "Release this version" 클릭
→ 게시 확인되면 어드민 Kill switches의 최소 버전을 1.0.1로 올려도 됨 (그 전엔 금지)
